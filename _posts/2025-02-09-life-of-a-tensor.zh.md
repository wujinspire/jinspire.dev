# 法国的首都是___

当大模型生成一个新词时，模型内部的矩阵是如何变化的？

# Embedding (嵌入)

我们从嵌入层开始。假设一个词等于一个token。

输入句子：The capital of France is ___

-> ['The', 'capital', 'of', 'France', 'is']

-> [464, 3361, 295, 2238, 318]，这是它们的Token ID

这形成了一个长度为5的序列。

GPT-2是进行分解的最佳模型，因为其他模型遵循类似的原理。

GPT-2有一个包含50,000个token的词汇表，每个token映射到一个768维的向量。

这意味着存在一个大小为 [50,000, 768] 的嵌入表。

查找嵌入表：
- The     = [0.316, 0.524,0.063, 0.481, 0.266, …]
- capital = [0.123, 0.234, 0.345, 0.456, 0.567, …]
- of      = [0.432, 0.543, 0.654, 0.765, 0.876, …]
- France  = [0.543, 0.654, 0.765, 0.876, 0.987, …]
- is      = [0.654, 0.765, 0.876, 0.987, 0.098, …]

-> 因此，我们获得了一个 [5, 768] 的矩阵！

# Attention (注意力)

在GPT-2 small中，多头注意力（Multi-Head Attention）有12个头。

一个关键的数学关系：12 * 64 = 768。

所以 [5, 768] == [5, 12, 64] == [5, 64] * 12

我们将有三个关键矩阵：Q, K, V。每个都是 [768, 768]。

让我们从Q开始。

因为Q的大小是 [768, 768] == [768, 12 * 64]。

我们将768中的一个拆分为12个头，每个头是 [768, 64]。

Q 一个头 = [5, 768] * [768, 64] = [5, 64]

Q = 12个头 = [5, 64] + [5, 64] + ... + [5, 64] = [5, 12 * 64] = [5, 768]

K和V是一样的。

K = [5, 768]

V = [5, 768]

这是最重要的注意力公式：

![attention_equation]({{ '/assets/images/posts/attention_equation.png' | relative_url }})

Q = [5, 768]

K^T = [768, 5]

QK^T = [5, 5]

Softmax(QK^T/√d) = [5, 5]

Softmax(QK^T/√d) * V = [5, 768]

我们还有一个输出投影矩阵 = [768, 768]，它不会改变V的大小。

输出投影(A) = [5, 768] * [768, 768] = [5, 768]

这仍然是 [5, 768]。

# Multi-Layer Perceptron (MLP, 多层感知机)

Attention输出 = [5, 768]

MLP有两层：一层扩展 [768 × 3072]，一层收缩 [3072 × 768]

变化：[5, 768] -> [5, 3072] -> [5, 768]

这仍然是 [5, 768]。

# 重复Attention + MLP 12层

(5, 768) -> (5, 768) -> (5, 768) … -> (5, 768)

这仍然是 [5, 768]。

# 最终输出

我们提取最后一行：[768]

然后，我们使用原始嵌入表 [50,000, 768] 映射回Token ID，检索最终单词：Paris

# 参数计数计算

50000 * 768 + (768 * 768 * 3 + 768 * 768 + 768 * 3072 * 2) * 12

= 38.4M + (7.08M) × 12 = 124M

它们是：embedding(50000, 768), KQV weights(768, 768), output projection(768, 768), MLP weights(768, 3072) * 2, 共12层。

参数细分：
- 38.4M → Embedding
- 21.2M → KQV matrix
- 7.1M → Output Projection
- 56.6M → MLP

# 总结
- 嵌入层将句子转换为 [5, 768] 矩阵。
- 多头注意力机制计算 Q, K, V，形状均为 [5, 768]。
- 应用 Softmax(QK^T / sqrt(d)) * V 得到一个新的 [5, 768]。
- MLP 扩展和收缩维度，输出另一个 [5, 768]。
- 对12个Transformer层重复此过程，保持最终形状 [5, 768]。
- 最后一行 [768] 使用嵌入表映射回token。
- 最终预测词："Paris"。
- 总参数 ~124M，主要分布在Embedding, Attention, 和 MLP中。

注意5是句子长度，实际生成过程填充到最大长度，1024。

768是每个token的维度，也称为 d_model。

12是注意力头的数量，也称为 h。

12也是Transformer层的数量，称为 n_layers。
